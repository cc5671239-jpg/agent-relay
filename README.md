# agent-relay —— AI 项目接力框架

> 让任何 AI Agent（ZCode / Claude Code / Codex / Cursor / 其他）在 5 分钟内接手你的项目，并完整交棒给下一个。

## 解决什么问题

长期由 AI 维护的项目，最大的风险不是代码写错，而是**上下文丢失**：换会话、换工具、换模型、换电脑之后，新 Agent 不知道项目是什么、做到哪一步、哪些决策不能推翻、哪些红线不能碰。

本框架用 6 份文档把项目状态变成"文件里的记忆"：

| 文件 | 角色 |
|---|---|
| `AGENTS.md` | 工作规则：必读顺序、工作流程、红线、任务手册 |
| `PROJECT_CONTEXT.md` | 项目记忆：当前状态 / 下一步 / 风险（最常更新） |
| `ROADMAP.md` | 阶段计划与验收标准 |
| `DECISIONS.md` | 决策记录（编号追加，不推翻，废弃才标记） |
| `CHANGELOG.md` | 变更日志（**必填执行 Agent 的工具+模型**） |
| `CLAUDE.md` | 指针文件（兼容只认 CLAUDE.md 的工具） |

三条铁律：

1. **状态唯一载体是文档**，会话是一次性容器；文档没写 = 工作没做完
2. **收尾必推送**：git 远端是唯一备份，不 push = 工作只完成一半
3. **变更必署名**：每条 CHANGELOG 记录执行 Agent 的工具+模型，可追溯、可断代分析

## 安装（作为 Agent 技能）

```bash
# 克隆本仓库到个人技能目录（仓库地址在本页面右上角 Code 按钮获取）
git clone <本仓库地址> ~/.agents/skills/agent-relay   # ZCode / 跨工具标准目录
git clone <本仓库地址> ~/.claude/skills/agent-relay   # Claude Code
```

其他工具（Codex / Cursor 等）：把 `SKILL.md` 的内容放进你的系统规则文件，或直接让 Agent 阅读本仓库。

**触发方式**：对 Agent 说"接手项目 / 开工 / 收尾 / 交接"，技能会自动介入；也可以显式调用 `/agent-relay`。

## 为新项目初始化框架

对 Agent 说：

> 用 agent-relay 技能给本项目初始化接力文档

Agent 会把 `assets/templates/` 中的 6 份模板复制到项目根目录并按项目实际填写。
