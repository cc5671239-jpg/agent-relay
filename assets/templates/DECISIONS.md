# DECISIONS —— 决策记录

> 回答「**为什么这样设计**」。所有重要的设计与技术选择记录于此——它是防止新 Agent 推翻既有设计的依据。
> 新决策**追加到文件末尾**，编号递增；不删除旧决策，被替代的标记「已废弃」并注明替代者。
>
> **格式**：编号 · 日期 · 状态（✅ 已采纳 / 🟡 建议中 / ⏸ 暂缓 / ❌ 已废弃）
> 每条包含：决策、背景/理由、备选方案（如有）、影响。
> 只记「为什么」，不记「做了什么」——做了什么去 `CHANGELOG.md`。
