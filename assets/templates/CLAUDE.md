# CLAUDE.md

本项目对所有 AI Agent 的工作规则、必读文件与注意事项统一维护在 **AGENTS.md** 中。

开始任何工作前，请先按 `AGENTS.md` 的顺序阅读：

1. `AGENTS.md` —— 入口：必读顺序、项目规则、红线
2. `PROJECT_CONTEXT.md` —— 项目当前状态
3. `HANDOFF.md` —— 最近一次交接
4. `USER_PROFILE.md` —— 用户开发画像
5. `WORKFLOW.md` —— 工作协议
6. `ROADMAP.md` / `DECISIONS.md` / `CHANGELOG.md` —— 方向 / 决策 / 历史
